# 실습의 목적
2026-09-04 폴더의 실습 목적은 그저 포트를 연결하는 것이었다.포트를 연결하여 웹을 띄우고 그 웹에서 기록을 할 경우 기록 목록에 내가 기록한 것들을 볼 수 있도록 하는 기능을 만들었다. 하지만 이는 컨테이너를 실행 중에만 볼 수 있고 컨테이너를 종료했다가 다시 실행한다고 하더라도 이전에 기록했던 내용들을 다시 확인할 수 없다.

## 실습 내용
오늘은 컨테이너를 종료한다고 하더라고 이전의 기록이 남을 수 있도록 Docker Volume을 사용하여 따로 json 파일을 통해 데이터를 저장하도록 하려한다.

### 용어
JSON : 데이터를 텍스트 파일 형태로 저장하는 형식
/data/study_logs.json : 컨테이너 내부에서 앱이 데이터를 저장할 파일 경로
마운트(mount) : 외부 저장소인 볼륨을 컨테이너 내부 경로에 연결하는 일
