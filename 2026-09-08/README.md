# 실습의 목적 및 내용
이번에도 동일하게 볼륨을 연결하여 실습한다. 다만 전날과 달리 이번에는 실시간으로 app.py의 내용을 바꿀 경우에 바로 이 수정사항이 반영이 되도록 만들었다.이를 통해 실무 개발 흐름처럼 로컬 컴퓨터 환경의 파일을 수정해도 이 파일이 컨테이너의 파일과 직접 연결이 되고 이에 따라 자연스레 웹 서버가 수정된 코드를 사용할 수 있도록 하였다.



## 용어
바인드 마운트 : 로컬 컴퓨터의 특정 폴더를 컨테이너 내부 경로에 직접 연결한다


### 명령어
docker run -d \
  --name docker-study-log-dev \
  -p 8000:8000 \
  -e FLASK_DEBUG=1 \
  --mount type=bind,source="$(pwd)",target=/app \
  --mount type=volume,source=study-log-data,target=/data \
  docker-study-log:dev

  - FLASK_DEBUG=1 은 app.py에 나와있듯이 환경변수가 1일 경우 개발 모드라는 것을 명시하기 위해서 필요한 변수이다.
  - 2개의 mount가 존재하는데 첫번째 마운트는 target을 보면 어느정도 유추가 가능하듯이 내 컴퓨터의 파일을 컨테이너 내부의 /app 경로와 연결시키는 행위이다.
  - 두번째 마운트는 전날 실습에서도 했듯이 컨테이너의 기록을 볼륨에 따로 기록하려고 만들어놓은 볼륨의 정보이다.
